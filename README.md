# Oman · Budget voyage

Application web en français, adaptée à Safari sur iPhone. Chaque voyageur renseigne ses dates, son billet et son hôtel, puis sélectionne ses repas et activités. L’application calcule le budget total, les dépenses réglées et le reste à économiser. La location et le carburant se règlent dans Paiements. Le bilan peut être exporté en PDF depuis l’application.

Les données sont enregistrées dans le navigateur ou dans l’application installée, sur l’appareil utilisé. Il n’y a ni compte ni synchronisation de groupe.

## Ouvrir ou héberger

Décompresser le ZIP. Sur ordinateur, ouvrir `index.html` pour essayer l’interface. Pour tester via un serveur local, lancer `python3 -m http.server 8000` dans le dossier et ouvrir http://localhost:8000.

Pour partager l’application via GitHub Pages, placer le contenu du dossier à la racine du dépôt, puis activer Pages sur la branche choisie et la racine. Vérifier les paramètres de visibilité du dépôt et du site avant d’envoyer le lien. Dans Safari sur iPhone, ouvrir ce lien, puis toucher Partager → Sur l’écran d’accueil.
